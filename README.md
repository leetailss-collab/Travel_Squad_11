# ✈️ Travel Squad 11 (가족 여행 일정 & 경비 관리 앱)

가족 여행 일정을 손쉽게 계획하고, 실시간 경로 지도 확인, 다중 경비 분할 입력, 4대 경비 분석 대시보드(1인당, 1일당, 1인 1일당, 고정비 vs 현지활동 비중)를 공유할 수 있는 통합 웹 애플리케이션입니다.

---

## 🛠️ 개발 환경 세팅 & 시작하기

자세한 세팅 방법과 트러블슈팅 가이드는 [**`git_guidelines.md`**](./git_guidelines.md) 문서에 정리되어 있습니다.

### 1. 필수 환경 변수 및 키 설정

새 컴퓨터에서 클론 후 백엔드 폴더(`backend/`)에 아래 2개 파일이 필요합니다.

1. **`backend/.env`** (네이버 지도 API 키)
   ```env
   PORT=5000
   NAVER_CLIENT_ID=사용자의_네이버_클라이언트_ID
   NAVER_CLIENT_SECRET=사용자의_네이버_클라이언트_SECRET
   ```
2. **`backend/firebase-service-account.json`** (Firebase Admin 서비스 계정키)

### 2. 패키지 설치 & 실행

```bash
# 1) 백엔드 & 프론트엔드 의존성 설치
cd backend && npm install
cd ../frontend && npm install

# 2) 로컬 서버 실행 (루트 폴더에서 run_local.bat 실행 권장)
# - 프론트엔드: http://localhost:3000
# - 백엔드: http://localhost:5000
```

## 📖 주요 기능

- 🗺️ **네이버 지도 연동**: POI 장소 명칭 검색 & 길찾기 앱 자동 연동
- 💵 **다중 경비 분할 입력**: 한 장소 내 입장료/주차비/식비 등 개별 카테고리 & 결제자 지정
- 📊 **경비 종합 분석표**: 1인당, 1일당, 1인1일당(가성비) 수치 및 고정비(숙박+교통) vs 현지활동 비중 분석
- 🍩 **SVG 도넛 차트**: 카테고리별 지출 백분율(%) 시각화
- 📱 **모바일 팝업 해제 및 반응형 웹**: 스마트폰 및 데스크탑 최적화 UX
